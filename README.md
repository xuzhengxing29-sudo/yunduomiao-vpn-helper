## 🚀 快速开始

### 第一步：解压并启动搭建助手
1. 下载本仓库中的 `云朵喵VPN搭建助手.zip`，**将整个压缩包解压到一个独立文件夹**（⚠️ 请勿直接在压缩包内双击运行）。
2. 双击运行 `云朵喵VPN搭建助手.exe`（程序会调用系统自带的 Edge WebView2 内核打开操作窗口）。
   - 如果 Windows 弹出「已保护你的电脑」，点击 **更多信息 → 仍要运行**。
3. 首次打开会进入激活界面，窗口中会显示当前电脑的 **机器码**，点击复制。

### 第二步：使用授权码生成器激活
1. 双击运行 `云朵喵授权码生成器.exe`。
2. 填入刚才复制的 **机器码**（可选填备注与有效期），点击生成即可获得对应的一串 **授权码**（本地首次使用会在同目录自动生成 `授权记录.json` 保存签发记录）。
3. 将生成的授权码粘贴回 `云朵喵VPN搭建助手.exe` 中，点击 **激活** 即可开始使用。
   > 注：授权码与电脑机器码绑定，仅对当前这台电脑有效。

### 第三步：一键搭建新服务器
- **VPS 系统要求**：`Ubuntu 22.04` / `Ubuntu 24.04` 或 `Debian 12`。
1. 在助手首页选择 **搭建新服务器**。
2. 填写 VPS 的 IP 地址与 `root` 密码，按界面提示一步步操作即可。
   - **重复搭建**：如果对已经搭好的服务器再次点击「搭建」，`3x-ui`、证书、入口线路、防暴力破解、自动更新、防火墙等已完成项会自动「跳过」，仅补充缺失项或端口变更项。
   - ⚠️ 搭建进行中请勿关闭窗口；关闭窗口后程序会自动退出。

### 第四步：导入客户端配置
搭建完成后，所有输出文件均保存在程序同级目录的 **`输出`** 文件夹中：
- **`.yaml` 文件**：电脑端使用 **Clash Verge** 通过「新建 → 本地文件」导入。
- **`_分享链接.txt`**：手机端使用 **v2rayNG** / **Hiddify** 从剪贴板导入。
- **`面板信息.txt`**：记录 `3x-ui` 面板地址、账号密码与 API 令牌（⚠️ 请妥善保管，不要发给他人）。

## 🛠️ 核心功能详解

### 1. 20+ 项问题检测与一键修复
在首页选择 **检测并修复问题**，连接服务器后会自动检查二十余项状态：
- TCP 是否被墙、Xray 运行状态、入口线路是否齐全
- 路由规则（住宅出口失效 / Google Play 转圈等）
- 住宅 IP 可用性、防火墙、证书续期、时间同步、BBR、磁盘与内存、配置文件是否过期等
- 支持自动修复的项目勾选后点击 **一键修复**，修完会自动复检；页面底部还提供 **常见问题自助** 指南。

### 2. 登录与本地密码记忆
- 登录页上方 **登录记录** 会保存连接过的服务器（`用户名@IP`、系统、上次登录时间、总登录次数及最近 10 次记录）。
- 勾选 **记住密码** 后，密码会通过 Windows DPAPI 在本机加密保存，**只有当前这台电脑的当前 Windows 账号才能解密**（拷贝到其他电脑无效）。请勿在公用或他人电脑上勾选。
- 点击「忘记密码」仅删除保存的密码；点击「✕」会连同登录记录一并删除。在 **安全设置** 中修改密码时，记住的密码会自动同步更新。

### 3. 住宅 IP / 线路识别与一键体检修复
- **自动识别手动配置**：自己在 `3x-ui` 中手动添加的住宅 IP（出站 + 路由规则，支持按用户邮箱分流和按入站分流两种写法）都能在 **管理线路** 中识别；若只配了出站忘记写规则，会提示点击 **配上线路**。
  - 注：入站协议需为 **Reality** 或 **Hysteria2**，其他协议会标记「协议不支持导出」。
- **体检所有线路**：在 **管理线路** 点击 **体检所有线路**，程序会从服务器逐条通过住宅 IP 访问外网，正常线路显示出口 IP 和运营商，异常线路整行标红并给出原因。
- **一键修复有问题的线路**：支持自动修复线路被停用、未挂到全部入口、规则指向出站不存在、规则顺序错误、代理协议选反（SOCKS5 / HTTP）等问题，并在修复后重启 Xray、复检及更新配置。若遇住宅 IP 到期、账密变更、未加白名单或达到自定义到期日/流量上限，会标明「需要你来处理」并给出解决建议。

### 4. 多住宅 IP 合并导出与防泄露
- **多出口合并**：在 **管理线路** 中勾选多个想要的出口，点击 **勾选的出口合并成一个配置**，会在 `输出` 文件夹生成 `自选出口_翻墙_合并.yaml`。导入 Clash Verge 后可在 `PROXY` 分组自由切换出口。
  - 每个出口均包含三层回落线路：`Hysteria2 8443` → `Hysteria2 443` → `Reality`，前一种不通会自动切换下一种。
  - 若线路名称中包含国家或城市（如日本、东京、美国、LA、US、香港等），导出时会自动匹配国旗图标。
  - 回国出口与翻墙出口规则方向相反，不会混用，会分别生成文件。
- **防泄露配置**：生成的 `.yaml` 默认开启虚拟网卡（TUN）模式、接管全部 DNS 查询并拒绝所有 IPv6 流量。
  - ⚠️ 为防止浏览器 WebRTC 泄露真实 IP，请在 Clash Verge 的「设置」中安装服务模式并开启 **虚拟网卡模式**（仅开「系统代理」时浏览器 WebRTC 不会走代理）。

### 5. 其他实用功能
- **管理线路**：查看服务器状态、各线路已用流量与在线情况；点击 **设置** 可限制流量、设置到期日、停用线路；点击 **备份面板** 可将面板数据导出到 `输出` 文件夹。
- **控制台**：直接在服务器上执行命令，界面上方提供常用快捷命令按钮。
- **安全设置**：修改服务器 SSH 登录密码及 `3x-ui` 面板用户名/密码（建议搭建完成后及时更改默认密码）。
- **AI 助手（右下角）**：支持接入 **DeepSeek、通义千问、Kimi、OpenAI** 等模型 API Key（点击「保存并检查」可免费校验配置是否正确；注意不要误填 `面板信息.txt` 里的面板 API 令牌）。
  - 自带 **25 篇 VPN 知识库**（搭建流程、协议选择、3x-ui 用法、常见故障等），也可在 `AI 助手 → 设置 → 打开知识库文件夹` 中放入自定义 `.md` / `.txt` 文档。
  - 新手可直接向 AI 提问（如「从头教我怎么搭」），涉及修改服务器的操作在执行前都会先向你确认。
