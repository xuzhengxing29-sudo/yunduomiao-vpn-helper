云朵喵 · VPN 搭建小助手
========================

1. 先把整个压缩包解压到一个文件夹（不要在压缩包里直接双击运行）。
2. 双击「云朵喵VPN搭建助手.exe」，会弹出一个小窗口（用的是电脑自带的 Edge 浏览器内核）。
3. 第一次打开需要激活：把窗口里显示的「机器码」复制发给作者，
   作者会回一串授权码，粘贴进去点「激活」。授权码只对这一台电脑有效。
4. 选「搭建新服务器」，填 VPS 的 IP 和 root 密码，按提示一步步点就行。
5. 搭好后，配置文件在程序旁边的「输出」文件夹里：
   - .yaml 文件：电脑上用 Clash Verge「新建 → 本地文件」导入
   - _分享链接.txt：手机 v2rayNG / Hiddify 从剪贴板导入
   - 面板信息.txt：3x-ui 面板地址和账号（不要发给别人）

出问题了？
- 首页选「检测并修复问题」，连上服务器后会自动检查二十多项：
  TCP 是否被墙、Xray 是否在运行、入口是否齐全、路由规则（住宅出口失效 / Google Play 转圈）、
  住宅 IP 是否可用、防火墙、证书续期、时间同步、BBR、硬盘内存、配置文件是否过期……
- 能自动修的打勾后点「一键修复」，修完会自动再检查一遍。
- 页面最下面有「常见问题自助」，例如只有某个人连不上时该怎么办。

登录和登录记录
- 登录页上方的「登录记录」列出登录过的服务器：用户名@IP、系统、上次登录时间、一共登录几次，点开还能看最近 10 次的时间。
- 登录时勾上「记住密码」，下次在登录记录里点「登录」就直接进去，不用再输。
  密码是用 Windows 自带的加密保存在这台电脑上的，只有当前这个 Windows 账号能解开；把文件拷到别的电脑上解不出来。
  公用电脑、别人的电脑上不要勾。「忘记密码」只删掉记住的密码，「✕」连记录一起删。
- 在「安全设置」里改了登录密码，记住的密码会跟着更新。

认出面板里已有的出口
- 你自己在 3x-ui 里手动配的住宅 IP（出站 + 路由规则），「管理线路」里一样能看到：每条线路从哪个出口出去、是什么协议。
  按用户（邮箱）分流和按入站分流两种写法都认。
- 配了出站但忘了写路由规则的，会单独提示，点「配上线路」就能用。
- 线路用的入站如果不是 Reality 或 Hysteria2，会标「协议不支持导出」，这种线路本软件生成不了配置文件。

找出有问题的住宅 IP，一键修复
- 「管理线路」点「体检所有线路」：从服务器上逐条经过住宅 IP 访问外网，正常的显示出口 IP 和运营商，有问题的整行标红并写明原因。
- 发现能修的问题时会出现「一键修复有问题的线路」按钮。软件能自动修的有：
  线路被停用、没挂到全部入口、规则指向的出站不存在、规则顺序不对、代理协议选反了（SOCKS5 / HTTP）。
  修完会重启 Xray、再检查一遍，并更新配置文件。
- 软件改不了的（住宅 IP 到期、账号密码被改、没加白名单、你自己设的到期日或流量上限到了）会标「需要你来处理」，下面写着该怎么办。

多个住宅 IP 放进同一个配置文件
- 「管理线路」里每条线路前面有个勾。勾上想要的出口，点「勾选的出口合并成一个配置」，
  输出文件夹里会多出「自选出口_翻墙_合并.yaml」。导入 Clash Verge 后，在 PROXY 分组里点哪个出口就用哪个。
- 每个出口里仍然是三种线路（Hysteria2 8443、Hysteria2 443、Reality），前一种不通会自动换下一种。
- 国旗：线路的显示名称里写了国家或城市（日本、东京、美国、LA、US、香港……），生成配置文件时会自动配上对应国旗，
  在 Clash 的代理列表里一眼能认出来。名字里没写国家就不加；已经带国旗的不会重复加。
- 回国出口和翻墙出口的规则相反，不能混在一起，会各自生成一个文件。
- 防泄露：配置文件默认开启虚拟网卡（TUN）模式、接管全部 DNS 查询、拒绝所有 IPv6。
  要让 WebRTC 也不泄露真实 IP，必须在客户端里把「虚拟网卡模式」打开（Clash Verge：设置 → 虚拟网卡模式，需要先装服务模式）。
  只开「系统代理」时，浏览器的 WebRTC 不走代理，会露出真实 IP。

已经搭好的服务器再点一次「搭建」
- 不会重装：3x-ui、证书、入口线路、防暴力破解、自动更新、防火墙，哪一项做过就跳过哪一项，日志里会写「跳过」。
- 只有缺的或者端口变了的才会重新配置。

其他功能
- 管理线路：查看服务器状态、每条线路的已用流量和在线情况；点「设置」可以限制流量、设置到期日、
  停用线路；「备份面板」把面板数据保存到输出文件夹。
- 控制台：直接在服务器上执行命令，上面有常用命令的按钮。
- 安全设置：修改 SSH 登录密码、3x-ui 面板的用户名和密码。建议搭建完把 root 密码换成自己的。
- AI 助手（右下角）：填入你自己的 AI API（DeepSeek、通义千问、Kimi、OpenAI 等），
  它可以回答问题，也可以帮你运行检测、修复、执行命令。会改动服务器的操作都会先问你。
  接入方法：点右下角「AI 助手」，先点你用的服务商名字（如 DeepSeek），再粘贴密钥，点「保存并检查」。
  检查不花钱，哪一项填错了会直接告诉你。密钥要到 AI 服务商的网站上创建；
  「面板信息.txt」里的 API 令牌是面板用的，不是 AI 的密钥。AI 接不上时看「帮助」里的说明。
  新手可以直接对 AI 说「从头教我怎么搭」，它会讲流程、给建议，连接服务器后还能替你一键搭建。
  AI 自带 25 篇 VPN 知识库（流程、协议选择、3x-ui 功能、常见故障等）。想补充自己的资料：AI 助手 → 设置 → 打开知识库文件夹，
  把 .md 或 .txt 文件放进去即可。

注意
- VPS 系统需要是 Ubuntu 22.04/24.04 或 Debian 12。
- 如果 Windows 提示「已保护你的电脑」，点「更多信息 → 仍要运行」。
- 关闭窗口后程序会自动退出；搭建进行中请不要关窗口。
