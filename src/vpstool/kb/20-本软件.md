# 本软件的常见疑问：激活、文件位置、报毒、重复运行
关键词：激活 授权码 机器码 报毒 杀毒 输出文件夹 日志 重复搭建 再运行一次 卸载 Edge 窗口打不开
激活：第一次打开需要授权码。把窗口里的机器码发给软件作者获取。授权码只对这台电脑有效，重装系统后机器码会变，需要重新获取。
杀毒软件报毒 / Windows 提示已保护你的电脑：程序没有数字签名，属于误报。点「更多信息 → 仍要运行」，或在杀毒软件里添加信任。
窗口打不开：程序用系统自带的 Edge 浏览器显示界面。如果电脑没有 Edge 也没有 Chrome，请先安装其中一个。
文件位置：都在程序所在文件夹里。「输出/服务器IP/」里是配置文件、面板信息和运行日志；「最近的服务器.json」只记 IP 和用户名；「AI设置.json」是 AI 的接口设置；「知识库」文件夹可以放自己的补充资料。
搭建中途失败了：解决问题后直接再运行一次「搭建新服务器」，已完成的步骤会自动跳过，不会重复安装或弄乱设置。
对已经搭好的服务器再运行一次搭建：安全，只会补上缺少的部分。
想彻底清除服务器上的 VPN：最干净的方法是在商家后台重装系统。
密码安全：SSH 密码只用于当次连接，不会保存到电脑上。
