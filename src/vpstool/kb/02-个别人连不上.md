# 只有某一个人连不上，其他人都正常
关键词：朋友 别人 一个人 个别 连不上 超时 自己正常 手机 电脑 握手失败
说明服务器没问题，问题在那个人的设备或网络。按顺序检查：
1. 客户端版本：Clash Verge Rev 必须是较新的版本，旧版内核不支持 Hysteria2 的 salamander 混淆，会一直超时。手机上用最新版的 v2rayNG、Hiddify 或 NekoBox。
2. 设备时间：电脑/手机的时间和真实时间差超过 1 分钟左右，Reality 会握手失败。在系统设置里打开「自动设置时间」并同步一次。
3. 网络限制：学校、公司、部分宽带会屏蔽 UDP，Hysteria2 用不了，改选 Reality 线路。反过来 Reality 不通就试 Hysteria2。也可以换手机热点测试，确认是不是网络的问题。
4. 配置文件过期：让线路的主人在软件里「重新生成配置文件」，把新的发给他。他要先删掉旧配置再导入新的。
5. 冲突：关掉其他 VPN、加速器（雷神、UU、奇游）、杀毒软件的网络防护。Clash 里打开 TUN 模式；Windows 上需要以管理员身份运行或安装服务模式。
6. 线路被停用：在软件「管理线路」里看这条线路是不是标了「已停用」，运行「检测并修复」可以重新启用。
