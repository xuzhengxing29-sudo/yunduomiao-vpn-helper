# 3x-ui 面板打不开 / 忘记面板地址和密码
关键词：面板 3x-ui x-ui 打不开 登录 地址 端口 路径 忘记密码 证书 不安全 面板信息
面板地址、用户名、密码都在程序旁边「输出/服务器IP/面板信息.txt」里。地址带随机端口和随机路径，缺一不可。
打不开：
1. 在国内直连：面板端口可能被墙，先连上自己的 VPN 再打开。
2. 浏览器提示证书不安全或已过期：运行「检测并修复」，修复「面板证书」。面板用的是 IP 证书，有效期只有几天，靠自动续期，续期需要临时打开 80 端口，软件已经设置好。
3. 面板服务没运行：「检测并修复」会重启它；或在控制台运行 systemctl restart x-ui 。
4. 防火墙没放行面板端口（改过端口后常见）：「检测并修复」会重新设置防火墙。
忘记密码或想修改：在本软件「安全设置」里直接改面板用户名和密码，不需要旧密码。
平时不需要登录面板：增删线路、住宅 IP、导出配置都可以在本软件里完成。在面板里手动改入站或路由，可能和本软件的设置冲突，改完后运行一次「检测并修复」。
