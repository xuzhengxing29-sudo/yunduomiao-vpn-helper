# 搭建和使用的建议（怎样更稳、更不容易被封）
关键词：建议 最佳实践 注意事项 防封 稳定 怎么用更好 经验 优化 隐蔽 避免被墙 长期使用
搭建时：
1. 用途选对：只翻墙就选「翻墙」，软件会屏蔽服务器访问国内网站——服务器同时大量访问国内站是被识别的重要特征。
2. 保持默认的三条入口。Reality 和 Hysteria2 互为备份，一条不通客户端会自动切到另一条。
3. 搭完立刻到「安全设置」换掉商家给的 root 密码。
4. 记下「输出」文件夹的位置，面板信息和配置文件都在里面，建议另外备份一份。
使用时：
1. 客户端打开 TUN 模式，用软件生成的配置文件（已处理好 DNS，避免泄露）。
2. 不要长时间跑满带宽（如 24 小时挂 BT 下载），流量特征异常容易被封；软件默认已屏蔽 BT。
3. 分享给别人时，每人一条独立线路，方便单独停用；人数别太多。
4. 给朋友用可以在「管理线路」里设置流量上限和到期日，避免某个人把月流量用光。
5. 敏感账号（需要固定 IP 的服务）固定用同一条住宅 IP 线路，不要来回切换国家。
维护：
1. 每隔一段时间、或感觉不对劲时跑一次「检测并修复」。
2. 改动较大之前先点「备份面板」。
3. 留意 VPS 的到期日和月流量，在商家后台设置自动续费或提醒。
4. 系统更新是自动的；提示需要重启时，找个没人用的时间重启一次。
IP 被墙后的顺序：先切 Hysteria2 → 等几天看是否解封 → 在商家后台换 IP → 重新生成配置文件。
不建议做的事：在面板里随意增删入站和路由规则；关闭防火墙；把面板端口改成常见端口；把配置文件发到群里或公开的地方。
