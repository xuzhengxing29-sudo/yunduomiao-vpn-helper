# 回国线路（海外看国内内容）
关键词：回国 国内 中国 版权 地区限制 B站 爱奇艺 腾讯视频 网易云 仅限中国大陆 留学生
用途：人在海外，想访问只对中国大陆开放的内容（视频、音乐、游戏、银行 App 等）。
需要：一个中国大陆的住宅 IP（或大陆的代理），在搭建时选「回国」或「两种都要」，把这个 IP 标记为「回国用」。
原理：回国配置文件只让国内网站走代理，其他网站直连，所以平时可以一直开着。
注意：
1. 回国线路不能开「屏蔽国内」。如果服务器同时做翻墙和回国，选「两种都要」，软件会按线路分别处理。
2. 没有大陆住宅 IP 时，回国线路走的是 VPS 自身的 IP，而 VPS 在海外，等于没有效果。
3. 仍然提示地区限制：部分 App 还会看 GPS、SIM 卡、系统语言和时区；视频网站可能识别出代理 IP，换一个住宅 IP 试试。
4. 海外 VPS 连回国内的大陆住宅 IP，延迟会比较高，看视频够用，打游戏不太行。
