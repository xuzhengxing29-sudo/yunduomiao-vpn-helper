# 从零开始：自己搭一个 VPN 的完整流程
关键词：从零 第一次 新手 小白 流程 步骤 怎么搭建 怎么开始 教程 入门 需要准备什么 全过程
整个过程分五步，全程大约半小时，其中软件自动搭建只要 5 分钟左右。
第一步：买一台 VPS（海外云服务器）。系统选 Ubuntu 22.04/24.04 或 Debian 12，内存 1GB 左右即可。买完会得到三样东西：IP 地址、SSH 端口、root 密码。怎么选见「怎么选 VPS」。
第二步（可选）：买住宅 IP。只是日常上网不需要；要用对 IP 要求严的服务（部分 AI、流媒体、电商）或要「回国」时才需要。
第三步：打开本软件，点「搭建新服务器」，填 IP、端口、密码，连接。然后选用途（翻墙 / 回国 / 两种都要），有住宅 IP 就粘贴进去，点「开始搭建」。软件会自动完成：安装 3x-ui 面板 → 创建 Reality 和 Hysteria2 三条入口 → 配置路由 → 开启防火墙、防暴力破解、自动更新、BBR 加速 → 生成配置文件。
第四步：把配置文件导入客户端。电脑用 Clash Verge Rev 导入 .yaml；手机用 v2rayNG / Hiddify / Shadowrocket 导入分享链接。见「配置文件怎么导入」。
第五步：收尾。到「安全设置」把 root 密码换成自己的；以后出问题点「检测并修复」。
AI 助手可以代办第三步里连接之后的部分：告诉它用途，它会在你确认后开始搭建。它不能替你输入密码，所以连接服务器这一步要自己填。
常见卡点：连接超时（IP 被墙或端口填错，见「软件连不上服务器」）；系统不是 Ubuntu/Debian（在商家后台重装系统）；搭建中途失败（解决后重新运行即可，已完成的步骤会跳过）。
