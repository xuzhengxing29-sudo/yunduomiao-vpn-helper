# TCP 443 连不上 / IP 被墙了怎么办
关键词：被墙 封锁 连不上 超时 timeout Reality TCP 443 GFW 全部连不上 突然 itdog
现象：所有人突然都连不上 Reality 线路，或检测里显示「从你的电脑连不上 Reality（TCP 443）」，但服务器上 Xray 正常运行。
原因：防火长城（GFW）封了这台 VPS 的 IP 的 TCP 连接。常见于大流量使用、IP 段本身被重点关注、或 IP 以前被别人用过。
判断：打开 https://www.itdog.cn/tcping/服务器IP:443 ，国内节点全红、海外节点正常，就是被墙。
处理：
1. 改用「Hysteria2」开头的线路。它走 UDP，TCP 被封时通常还能用。本软件默认建了 UDP 443 和 UDP 8443 两条。
2. 如果配置文件里没有 Hysteria2 线路，运行「检测并修复」，它会补上入口，然后重新导入配置文件。
3. Hysteria2 也不通，说明 UDP 也被封或 IP 被完全屏蔽，只能在 VPS 商家后台更换 IP（搬瓦工是付费换 IP），换完用新 IP 重新连接软件，点「管理线路 → 重新生成配置文件」。
4. 被墙通常几天到几个月后可能自动解封，但不保证。
预防：不要把线路分享给太多人；不要长时间跑满带宽；翻墙模式下保持「屏蔽服务器访问国内网站」。
