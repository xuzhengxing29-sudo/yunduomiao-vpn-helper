# 用什么协议好？Reality、Hysteria2、VMess、Trojan、Shadowsocks、WireGuard 怎么选
关键词：协议 选择 哪个好 推荐 Reality VLESS Hysteria2 VMess Trojan Shadowsocks SS WireGuard TUIC CDN Cloudflare WebSocket 区别 对比 建议
结论：个人自用，VLESS+Reality 做主力，Hysteria2 做备用和加速。本软件默认就是这个组合，一般不需要改。
各协议特点：
- VLESS + Reality（TCP）：伪装成访问一个真实的大网站（如 icloud.com），不需要自己买域名和证书，目前抗识别能力最好、最省事。缺点：走 TCP，IP 被墙后就不通。
- Hysteria2（UDP/QUIC）：在丢包、拥堵的线路上速度明显更好，TCP 被封时常常还能用。缺点：部分网络（校园网、公司网）屏蔽或限速 UDP。所以它和 Reality 正好互补。
- TUIC：和 Hysteria2 类似的 UDP 协议，二选一即可，Hysteria2 客户端支持更广。
- Trojan：伪装成 HTTPS 网站，需要自己的域名和真实证书。稳定，但准备工作多，效果不比 Reality 好。
- VMess：较老的协议，对设备时间要求严格，直接裸用容易被识别。通常只在「WebSocket + TLS + CDN」组合里使用。
- Shadowsocks：简单、速度快，但直连国外服务器在国内很容易被识别并封端口。适合做中转链路的一段，不建议作为翻墙主力。
- WireGuard：是正经的 VPN 协议，特征明显，过墙几乎必被封。不要用来翻墙；适合回国、异地组网等不过墙的场景。
- CDN 方案（VLESS/VMess + WebSocket/gRPC/XHTTP + Cloudflare）：流量经 Cloudflare 中转，IP 被墙了也能用，是「救活被墙 IP」的办法。需要自己的域名，速度通常比直连慢，配置复杂，属于进阶玩法。
怎么选：
- 新手、自用、几个人分享：保持默认（Reality + Hysteria2）。
- 所在网络屏蔽 UDP：只用 Reality。
- 晚高峰很卡：优先用 Hysteria2。
- IP 被墙又不想换 IP：先试 Hysteria2；不行再考虑 CDN 方案。
- 回国：协议不重要（不过墙），关键是要有中国大陆的出口 IP。
端口建议：用 443。它是 HTTPS 的标准端口，流量最不显眼；不要用一看就奇怪的高位随机端口做主力。
Reality 伪装站（SNI）建议：选国外、支持 TLS 1.3 和 HTTP/2、访问量大的站，最好和 VPS 在同一地区。默认的 www.icloud.com 适用面广；不要选被墙的站，也不要选国内站。
