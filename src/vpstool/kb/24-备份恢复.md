# 备份和恢复面板数据
关键词：备份 恢复 还原 数据库 x-ui.db 导出 导入 迁移 搬家 丢失 误删
备份：「管理线路 → 备份面板」。会把面板数据库保存到「输出/服务器IP/面板备份_日期.db」。里面包含所有入口、线路、路由和住宅 IP 设置。建议在大改动之前、以及平时每隔一段时间备份一次。
这个文件很敏感（含所有线路的密钥和住宅代理的账号），不要发给别人。
恢复：登录 3x-ui 面板网页 → 首页的「备份与恢复」→ 导入数据库，选择备份的 .db 文件。恢复后面板会重启，再回到本软件点「管理线路 → 重新生成配置文件」。
迁移到新 VPS 的两种方式：
1. 简单方式（推荐）：直接在新机器上用本软件「搭建新服务器」，重新添加住宅 IP。所有配置文件都会是新的。
2. 保留原线路：先在新机器上搭建，再到面板里导入旧机器的备份。注意备份里的服务器 IP 是旧的，导入后要在本软件里「重新生成配置文件」；Hysteria2 的证书路径相同，软件搭建时已生成。
配置文件（.yaml）不需要单独备份，随时可以重新生成；真正需要保管好的是「面板信息.txt」和面板备份。
