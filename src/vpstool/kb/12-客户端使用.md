# 配置文件怎么导入、用哪个客户端
关键词：导入 配置文件 yaml 分享链接 Clash Verge v2rayNG Hiddify Shadowrocket 小火箭 苹果 安卓 手机 电脑 Mac TUN 订阅 EOF
文件在程序旁边「输出/服务器IP/」文件夹里，每条线路一个 .yaml 和一个「_分享链接.txt」。
Windows / Mac：用 Clash Verge Rev。打开「订阅」→「新建」→ 类型选「本地文件」→ 选择 .yaml → 保存后点一下选中它。然后在「代理」页选线路，在「设置」里打开「系统代理」或「TUN 模式」（推荐 TUN）。
安卓：v2rayNG、Hiddify、NekoBox。打开「_分享链接.txt」，复制一行链接，在 App 里选「从剪贴板导入」。Clash Meta for Android 可以直接导入 .yaml。
iPhone / iPad：Shadowrocket（小火箭，需非中国区 Apple ID 购买）、Streisand、Hiddify。复制分享链接后打开 App 会提示导入。
每个配置文件里通常有 3 条线路（Reality、Hysteria2-443、Hysteria2-8443）和一个「自动切换」组，默认选自动切换即可，一条不通会自动换下一条。
订阅更新失败、提示 EOF：本软件生成的是本地文件，不是订阅链接，不需要也不能「更新订阅」。删除那条订阅，按上面的方法导入本地文件。
配置文件相当于钥匙：发给别人时只发他要用的那条线路的文件，不要把整个文件夹发出去，更不要发「面板信息.txt」。
