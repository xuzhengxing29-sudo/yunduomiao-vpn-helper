# 怎么选 VPS、选什么系统和配置
关键词：买 选购 VPS 服务器 推荐 搬瓦工 Vultr 系统 Ubuntu Debian 配置 内存 线路 机房 价格 KVM OpenVZ
系统：Ubuntu 22.04 / 24.04 或 Debian 12（本软件只支持这两种）。不要选 CentOS、Windows。
配置：1 核 1GB 内存就够几个人用；512MB 也能跑，软件会自动加虚拟内存。硬盘 10GB 以上。
虚拟化：必须是 KVM。OpenVZ / LXC 的小鸡不支持 BBR 和防火墙，本软件会拒绝。
地区：翻墙给国内用，优先日本、香港、新加坡、美国西海岸（洛杉矶）；延迟依次升高。
线路：价格差别主要在这里。普通线路晚高峰会慢；CN2 GIA、联通 9929、移动 CMIN2 这类「优化线路」贵但稳定。预算有限就先买普通的试试。
流量：每月 500GB–1TB 对个人足够。
付款：很多海外商家支持支付宝。注意查看是否支持退款、换 IP 是否收费。
买完后你会拿到：IP 地址、SSH 端口、root 密码——这三样就是本软件「连接」页要填的。
是否需要住宅 IP：只是日常翻墙看视频查资料，不需要。需要注册/使用对 IP 要求严格的服务（部分 AI、流媒体、金融、电商平台）时再买。
