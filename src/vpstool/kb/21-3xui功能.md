# 3x-ui 面板有哪些功能，哪些已经在本软件里
关键词：3x-ui x-ui 面板 功能 介绍 能做什么 入站 客户端 订阅 路由 出站 WARP Telegram 备份 证书 有什么用
3x-ui 是装在服务器上的网页管理面板，底层是 Xray 内核。它负责「开哪些入口、谁能用、流量怎么走」。
本软件已经包办、不需要登录面板的功能：
- 入站（入口）：自动创建 VLESS+Reality（TCP 443）和 Hysteria2（UDP 443、8443）。
- 客户端（线路）：新增、删除、启用/停用、查看每条线路已用流量和是否在线、设置流量上限和到期日、重置流量——都在「管理线路」里。
- 出站和路由：住宅 IP 出口、屏蔽国内、谷歌例外，由「管理线路」和「检测并修复」维护。
- 服务器状态：CPU、内存、硬盘、流量、Xray 版本，在「管理线路」页顶部。
- 备份：「管理线路 → 备份面板」把面板数据库下载到「输出」文件夹。
- 证书续期、防火墙、fail2ban、重启 Xray、看日志：在「检测并修复」和「控制台」里。
- 面板账号密码：在「安全设置」里改。
下面这些进阶功能本软件没有做成按钮（普通用户用不到）。可以登录面板网页操作（管理线路 → 打开 3x-ui 面板），也可以直接让 AI 助手代办：它能查面板的接口文档，在你确认后替你调用：
- 其他协议的入站：VMess、Trojan、Shadowsocks、WireGuard、TUIC、HTTP/SOCKS 等，以及 WebSocket、gRPC、XHTTP 等传输方式。
- 订阅链接：给每个客户端生成一个网址，客户端定时自动更新。本软件用的是本地配置文件，更简单也更隐蔽；需要订阅功能的话在面板「设置 → 订阅」里开启。
- 限制同时在线的 IP 数、按周期自动重置流量（每月重置等）。
- Telegram 机器人：流量预警、到期提醒、登录通知、定时备份。
- WARP 出站：通过 Cloudflare WARP 出网，用于解锁部分服务或给 IPv6-only 机器加 IPv4。
- 切换 Xray 内核版本、更新 geoip/geosite 规则文件、两步验证、多节点管理。
在面板里手动改了入站或路由之后，建议回本软件跑一次「检测并修复」，确认没有和软件的设置冲突。
