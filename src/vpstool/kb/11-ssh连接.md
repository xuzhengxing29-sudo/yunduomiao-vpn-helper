# 软件连不上服务器（SSH 连接失败）
关键词：SSH 连接失败 超时 拒绝 密码错误 认证失败 22 端口 root 登录不上 指纹变了 被封禁
1. 提示超时：IP 或端口填错；服务器关机/欠费（去商家后台看）；人在国内且这台 IP 被墙——先打开一个能用的 VPN（TUN 模式）再连。
2. 提示拒绝连接：SSH 端口不对。有的商家不是 22（搬瓦工是随机端口，在 KiwiVM 后台首页能看到）。
3. 提示用户名或密码不对：检查大小写和前后空格；刚重置密码要等一两分钟；有的商家默认用户不是 root（如 ubuntu、debian、admin），需要该用户能免密 sudo。
4. 连续输错密码被封：fail2ban 会封 1 小时。换个网络（手机热点）或等一小时，或在商家后台的网页控制台里运行 fail2ban-client unban --all 。
5. 提示服务器身份指纹和上次不一样：如果你刚重装过系统，属于正常，删除程序旁 known_hosts.txt 里对应那一行后重试；否则不要继续，可能有人冒充服务器。
6. 忘记 root 密码：在商家后台重置（搬瓦工：KiwiVM → Root password modification）。
