# 速度慢、延迟高、看视频卡
关键词：慢 卡 延迟 ping 高 丢包 晚高峰 带宽 BBR 线路 CN2 GIA 9929 测速
先分清是哪一段慢：
1. 晚上 8 点到 12 点慢、白天正常：国际出口晚高峰拥堵。换 Hysteria2 线路通常会好一些；根本解决要换线路更好的 VPS（如 CN2 GIA、9929、CMIN2 等针对中国优化的线路）。
2. 一直慢：在控制台点「负载和内存」看服务器是否满载；运行「检测并修复」确认 BBR 已开启、内存硬盘正常。
3. 只有住宅 IP 线路慢：住宅代理本身慢，换地区或换代理商；直连线路正常就说明 VPS 没问题。
4. 只有某个网站慢：可能是那个网站对机房 IP 限速（如部分流媒体），试试住宅 IP 线路。
参考：VPS 到国内的延迟，美西 150–200ms、日本/香港 50–100ms 属于正常。延迟高不一定速度慢，看视频主要看带宽和丢包。
测速方法：连上线路后打开 https://fast.com 或 https://www.speedtest.net 。
