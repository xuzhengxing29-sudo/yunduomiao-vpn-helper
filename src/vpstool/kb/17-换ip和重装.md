# 换了 IP / 重装了系统 / 换了一台 VPS 之后怎么办
关键词：换IP 更换IP 新IP 重装 重做系统 迁移 换服务器 搬家 配置失效
只换了 IP（系统没动）：服务器上的设置都还在。在本软件里用新 IP 重新连接，进入「管理线路 → 重新生成配置文件」，把新文件重新导入客户端并发给使用的人。旧配置文件里写的是旧 IP，全部作废。如果住宅代理设了 IP 白名单，记得把新 IP 加进去。
重装了系统：一切清空，等于一台新服务器。连接时如果提示「身份指纹和上次不一样」，删除程序旁 known_hosts.txt 里对应的那一行。然后选「搭建新服务器」重新搭建；住宅 IP 信息需要重新填。
换了一台新 VPS：直接对新机器「搭建新服务器」。旧机器上的线路不会自动搬过去。
无论哪种情况，旧的配置文件都不能用了，都要重新导入。
