# 住宅 IP 出口不工作 / 显示的还是 VPS 的 IP
关键词：住宅IP 住宅代理 出口 socks5 落地 显示VPS 白名单 proxyconnect EOF 到期 静态住宅 ISP
住宅 IP 的作用：让网站看到的是当地家庭宽带的 IP，而不是机房 IP。流量路径是 你 → VPS → 住宅代理 → 网站。
显示的还是 VPS 的 IP：路由规则顺序不对或规则丢了。运行「检测并修复」，修复「路由规则」。
线路完全打不开网站（检测提示「住宅出口连不上」，或日志里有 proxyconnect、EOF、connection refused）：是住宅代理本身的问题，软件修不了：
1. 住宅 IP 到期或流量用完：到代理商后台查看。
2. 账号密码或端口变了：代理商重置过。在「管理线路」删掉这条，用新信息重新添加。
3. 代理商要求 IP 白名单：把 VPS 的公网 IP 加到代理商后台的白名单里。
4. 协议填错：注意区分 SOCKS5 和 HTTP，端口通常不同。
被检测为机房 IP：买到的不是真住宅，找代理商换，或换一家。可以在 https://ipinfo.io 查看 IP 的类型。
速度慢：住宅代理普遍比 VPS 直连慢、延迟高，属于正常现象；选离 VPS 近的地区会好一些（如 VPS 在洛杉矶就选美西的住宅 IP）。
