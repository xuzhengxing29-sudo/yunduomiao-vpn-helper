          常见问题
          
      只有某一个人连不上，别人都正常
        
            
      • 让他把 Clash Verge Rev 更新到最新版。旧版本不支持 Hysteria2 的混淆，会一直超时。
        • 
            
      • 检查他电脑或手机的时间是否准确，时间差太多会握手失败。
        • 
            
      • 学校、公司的网络经常屏蔽 UDP，让他改选 Reality 开头的线路；反过来 Reality 不行就选 Hysteria2。
        • 
            
      • 把「重新生成配置文件」后的新文件发给他，删掉旧的再导入。
        • 
            
      • Clash 里打开「TUN 模式」，并关掉其他 VPN 或加速器（如雷神、UU），它们会抢网卡。
        • 
          
      
          
      所有人突然都连不上
        
            
      • 先运行一次检测。如果显示「TCP 443 连不上」，说明 IP 的 TCP 被墙了，改用 Hysteria2 线路。
        • 
            
      • 到 VPS 商家后台看服务器是否开机、是否欠费、流量是否用完。
        • 
            
      • 如果 Hysteria2 也不通，在商家后台更换 IP（搬瓦工等商家支持付费换 IP），再回来「重新生成配置文件」。
        • 
          
      
          
      Google Play、谷歌商店下载一直转圈
            
      翻墙模式会屏蔽国内网站，而谷歌的下载服务器有一部分在国内域名上。检测里的「路由规则」会自动加上谷歌例外，修复后重新导入配置文件即可。
      
          
      担心 DNS 泄露 / 网站识别出你在国内
            
      用本工具生成的配置文件（已开启 fake-ip，并把国外域名交给代理解析），在 Clash 里打开 TUN 模式。旧的配置文件请重新生成。
      
          
      住宅 IP 线路显示的是 VPS 的 IP
            
      通常是路由规则顺序不对，运行检测修复即可。如果检测提示「住宅出口连不上」，是住宅 IP 本身的问题：到期、账号密码变了，或者代理商要求把 VPS 的 IP 加白名单。
      
          
      速度慢、延迟高
        
            
      • 晚上 8 点到 12 点国际线路拥堵是常见现象，Hysteria2 线路在拥堵时通常比 Reality 快。
        • 
            
      • 检测里确认「BBR 加速」已开启。
        • 
            
      • 住宅 IP 本身也会慢，可以在「管理 → 体检所有线路」里看延迟，或换成离你更近的地区。
        • 
          
      
          
      面板打不开 / 浏览器提示证书不安全
            
      国内直连面板可能被墙，先连上自己的 VPN 再打开。证书过期的话运行检测，会自动修复续期。
      
          
      AI 助手提示错误、接不上
        
            
      • 在 AI 助手的设置里先点一下服务商的名字（比如 DeepSeek），地址和模型会自动填好，再粘贴密钥，点「保存并检查」。检查不花钱，会直接告诉你哪一项不对。
        • 
            
      • API 地址要填接口地址（DeepSeek 是 https://api.deepseek.com/v1），不是你登录、充值的那个网页地址。填成网页地址时软件会自动改过来。
        • 
            
      • 密钥要到 AI 服务商的网站上创建，一般是 sk- 开头的一长串。「面板信息.txt」里的 API 令牌是 3x-ui 面板用的，不能填在这里。
        • 
            
      • 提示被防火墙拦截：用国内的服务商时先关掉 VPN 再试；用国外的服务商（如 OpenAI）时要开着 VPN。
        • 
            
      • 提示余额不足：到服务商网站充值。新注册的账号通常要先充值才能调用。
        • 
          
      
          
      订阅更新失败、提示 EOF
            
      本工具生成的是本地配置文件，不需要订阅链接。在 Clash 里删除那条订阅，改为导入「输出」文件夹里的 .yaml 文件。
      
          
      连接服务器时提示超时
            
      在国内连海外 VPS 的 SSH，如果 IP 被墙也会超时。先打开一个能用的 VPN（TUN 模式）再连接；或者在商家后台确认 SSH 端口。
